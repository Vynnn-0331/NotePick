# 本地商品图片使用说明

完整文件夹：C:\Users\liuch\Desktop\大作业\NotePick\frontend\public\product-images

1. 打开同目录「图片清单.csv」，按品牌、完整型号、CPU和容量找到商品ID。
2. 将自己有权使用的图片放入这个目录，推荐直接命名为「商品ID.jpg」，也支持.jpeg、.png、.webp。例如：np-413c27d11a0df17c7146.jpg。
3. 开发服务器运行时新增/删除图片会自动刷新，卡片和详情使用同一张。生产预览或提交构建需要重新运行npm --prefix frontend run build。
4. 若想保留中文文件名，编辑mapping.json，对应ID的null改为文件名，例如："np-413c27d11a0df17c7146": "星耀14.webp"。文件必须在本目录，不能填网址、其他文件夹或绝对路径。没有文件时自动占位，不借用其他机型。
5. 同型号不同配置可以在mapping.json指向同一张已确认机身外观图片。照片里的配置标注不得与实际商品混淆。不要把不同年份/型号混用。

程序不再搜索、下载或生成商品图片。现有外链不再使用。联网发现及同品牌备选均为纯文字，没有图片或占位。CSV是方便查找的清单，不是原始Excel，不影响商品数据库。

本批图片已从Desktop/photo移动合并到本目录，保留原文件名；新增支持AVIF。mapping.json将同名Windows配置指向同一文件，MacBook按型号及尺寸匹配。映射报告：data/processed/local_photo_import.json。图片原文件未压缩或改画布，页面使用object-fit:contain等比例自适应显示。
