## 使用原则

1. **知识库不局限于 NotePick 当前收录的笔记本。** 可覆盖 Intel、AMD、Apple、NVIDIA、Qualcomm 等主流芯片家族；增加新型号时应附来源。
2. 将信息分为：**官方规格事实**、**基于产品定位的定性推断**、**同口径测试支持的性能结论**。三者不能混为一谈。
3. **CPU、GPU、内存、显卡功耗、散热和软件生态共同影响使用体验**。单个型号不能代表整机表现。
4. 对于未核实的具体型号，不编造跑分、帧率、续航或“性能高出百分之几”。可以给出保守的用途提示，同时注明证据不足。
5. 本知识库只描述硬件与性能；**用户预算、偏好权重、推荐数量、联网调用时机属于推荐系统设计，不在这里写死。**

# 第一层｜硬件基本知识

## 1. CPU 是什么

CPU（中央处理器）承担通用计算任务，例如程序执行、网页交互、编译、数据处理和部分游戏逻辑。判断CPU时需要区分：

- **厂商与家族**：Intel Core / Core Ultra，AMD Ryzen / Ryzen AI，Apple M 系列等。
- **具体型号和代际**：例如 Core i5-13420H、Core Ultra X7 358H、Ryzen 7 H 255。数字和后缀必须作为完整型号识别，**不同家族不能仅按“5/7/9”或数字大小比较性能**。
- **核心与线程**：核心数量有意义，但不同架构、大小核组合和软件负载之间不能直接等价。
- **功耗与散热设计**：同一处理器在不同笔记本里，持续负载表现可能不同。
- **指令集/平台**：Windows x86 软件与 Apple Silicon 上的 macOS 软件在兼容性、原生优化和转译开销方面可能不同。

### 常见 CPU 命名举例

| 家族 | 型号示例 | 可直接确认什么 | 不能仅凭名称断言什么 |
|---|---|---|---|
| Intel Core | Core i5-13420H、Core 5 320 | 处理器所属产品家族及具体型号 | 比所有旧款 i7 更快 |
| Intel Core Ultra | Core Ultra 5 325、Core Ultra X7 358H | 不同 Ultra 型号、架构/平台的身份 | Ultra X7 在任何软件中都比 Ultra 7 快 |
| AMD Ryzen | Ryzen 5 7530U、Ryzen 7 H 255 | Ryzen 产品家族与型号 | Ryzen 7 一定比另一代 Ryzen 5 快 |
| Apple Silicon | Apple M5、M5 Pro、M5 Max | Apple 芯片系列及不同定位 | GPU 核心数能直接对比 NVIDIA CUDA 核心数 |

> **注意**：CPU 名称中“酷睿 = Core”，“锐龙 = Ryzen”；数据库应统一命名，同时保留原文以便追溯。

## 2. GPU 是什么

GPU（图形处理器）负责图形渲染、视频相关加速及部分GPU计算任务。与CPU不同，它在游戏、3D渲染、部分AI和创作软件中尤其重要。

### 集成 GPU 与独立 GPU

- **集成显卡 / 核显（integrated GPU）**：通常集成于CPU或SoC中；常见于轻薄本。名称可能包含 Intel Arc、AMD Radeon 或 Apple GPU，并不因此变成独显。
- **独立显卡（discrete GPU）**：独立的GPU芯片，笔记本常见 NVIDIA GeForce RTX Laptop GPU；通常有独立显存和单独功耗预算。
- **同时具备两者**：部分笔记本既有核显又有独显。若商品表只允许填写一个主要GPU，应记录主要独显，并在必要时补充另一颗GPU的信息。

### 常见 GPU 例子

| GPU | 类型 | 合理的初步理解 | 注意事项 |
|---|---|---|---|
| Intel Graphics | 集成 | 通用的英特尔集显名称 | 名称比较笼统，**无法唯一对应性能等级** |
| Intel Arc 130V | 集成 | 特定 Intel 平台的内置 GPU | 要核对整机实际启用的型号 |
| Intel Arc B390 | 集成 | Core Ultra Series 3 的部分处理器所用内置 GPU | 核显，不是 NVIDIA 式独显 |
| AMD Radeon 780M | 集成 | AMD 某些移动处理器的内置 GPU | 不同内存与整机散热可能影响表现 |
| NVIDIA GeForce RTX 5060 Laptop GPU | 独立 | 面向游戏与GPU加速工作负载 | 与桌面 RTX 5060 不同；整机功耗很重要 |
| NVIDIA GeForce RTX 5070 Ti Laptop GPU | 独立 | RTX 50 Laptop 产品线中的较高定位型号 | 不能不看功耗就推算某台机器的帧率 |
| Apple M 系列内置 GPU | 集成式 SoC GPU | 与 Apple 统一内存架构结合 | 不应在二分类数据中写为独显；须考虑软件生态 |

**可核实例子：** Intel 官方列出 Core Ultra X7 358H 搭配 Arc B390 GPU；AMD 官方列出 Ryzen 7 H 255 的显卡为 Radeon 780M；NVIDIA 官方将 RTX 5060/5070 Ti 列为 Laptop GPU，并给出不同功耗范围。详见文末来源。[1][2][3]

## 3. 容易混淆的概念

- **GPU显存 vs 系统内存**：独显通常有自己的显存；核显通常共享系统内存；Apple 使用统一内存。不能简单把“16GB统一内存”等价成“16GB独显显存”。
- **NPU**：用于某些AI推理任务的专用单元；存在NPU不代表CPU/GPU整体性能更高。
- **CPU核数 vs GPU核心数**：二者计算单元不同；不同GPU厂商的“核心数”也不能横向相除、相乘来比较。
- **屏幕刷新率**：144Hz屏幕不保证游戏能达到144FPS。
- **产品类别**：轻薄本可能配备独显；游戏本也可能包含核显。机型定位不等于GPU类型。

# 第二层｜性能比较知识

## 4. 性能是多维的，不应只有一个总名次

### CPU 建议分别比较

| 维度 | 常见任务 | 可接受的证据 |
|---|---|---|
| 单核/响应 | 日常交互、部分设计操作、部分游戏 | 同版本、同测试口径的单核成绩 |
| 多核/持续负载 | 编译、批量计算、多线程渲染 | 多核成绩＋持续功耗和散热信息 |
| 能效 | 离电办公、移动创作 | 同条件功耗/任务完成时间、规范的续航实测 |
| 平台兼容 | 软件开发、工程应用 | 应用官方系统要求、原生支持及兼容性资料 |

### GPU 建议分别比较

| 维度 | 常见任务 | 可接受的证据 |
|---|---|---|
| 游戏渲染 | 1080p、1440p游戏 | 同游戏、同画质、同分辨率、同版本的FPS测试 |
| 图形创作 | 3D建模、渲染、特效 | 相同渲染器、相同项目的成绩及显存要求 |
| GPU计算/AI | 推理、训练、图像处理 | 具体框架的支持情况、模型规模、实测速度 |
| 视频工作流 | 编码、解码、剪辑 | 编码器支持、软件加速路径与实际导出测试 |
| 整机稳定表现 | 长时间高负载 | 笔记本的GPU功耗、温度、持续运行表现 |

## 5. 可使用的比较结论有三个强度

**A. 规格事实（置信度高）**  
例如：“RTX 5060 Laptop GPU 属于独立GPU”“Ryzen 7 H 255 集成 Radeon 780M”。来自厂商规格，可以直接用于识别与兼容性判断。**规格事实不等于跑分结论。**

**B. 定性定位（置信度中等，需说明依据）**  
例如：“相比主要面向轻办公的通用核显，配有适当功耗与散热条件的 RTX Laptop 独显机型通常更适合较重的3D图形任务。”这是用途方向判断，不是所有具体机型的绝对排名。

**C. 实测比较（需要匹配条件）**  
例如：“在某一基准测试的特定版本中，A机型的GPU成绩高于B机型。”应附测试来源、日期、软件版本、机型、功耗/画质/分辨率等上下文。没有这些条件，不应写精确百分比。

### 5A-4. 在笔记本推荐中怎样“灵活使用”这些榜单

**可以使用的宽松推断：**

- 若两颗**同一类别、同一图中**的芯片纵向相隔很大，可以判断其图示综合性能档次明显不同，例如桌面 RTX 5090 的图示位置高于 GTX 1650；但这不等于具体游戏必然快固定倍数。
- 若芯片处在图上相邻区域，可以只写“性能定位接近”，不必排出第17名、第18名。
- 可以借助图识别产品家族在不同时期的定位，例如高端桌面 Ryzen 9/Threadripper 与旧 Core 2 Duo 并非同等级产品。
- 图上没有的现代笔记本型号，回到**官方规格＋可核实的移动端测试＋本知识库已有定性描述**；不因缺席而判低分。

**不能跨越的四条底线：**

1. 不把桌面 CPU 与移动 CPU 的同名近似型号视为同一性能；尤其注意 `K/H/HX/U/V` 等后缀。
2. 不把桌面 GPU 与 `Laptop GPU` 视为同一个产品。
3. 不把天梯图的纵向距离转换成编造的“性能评分 82/100”或百分比。
4. 不把“图中性能较强”等同于“更省电、更便宜、更适合所有软件”。

| 中高多核吞吐 | 30,000–39,999 | Core Ultra X7 358H：约33,540；Core Ultra 7 356H：约34,423；Core Ultra X9 388H：约36,504 | 较强的日常生产与多任务处理能力 |
| 主流多核吞吐 | 20,000–29,999 | Ryzen 7 H 255：约28,247；Core Ultra 5 225H：约27,986；Apple M5 10核：约26,738 | 足以处理大量日常办公、学习及一般开发工作，是否适合重型任务仍需细看 |
| 更低 / 数据不足 | <20,000 或未取得可比数据 | 例如部分旧款低功耗处理器、未核验的新型号 | 不能仅凭家族名直接决定等级 |

以上 **不是**“Core Ultra 9 一定强于 Ryzen 9”的规则：只有列出的**完整型号及测试值**支持相应排序。同系列不同代际的处理器也可能跨等级。特别注意 Apple、Windows、ARM 平台的软件执行环境不完全相同。

### CPU 可核验的直接比较

- **Core Ultra X7 358H > Ryzen 7 H 255（在 PassMark 单核与多核项目中）**：2026-10-27 的页面记录约 33,541 vs 28,247（CPU Mark），以及 4,057 vs 3,669（单线程）。因此在这些基准项目中可以判断前者领先，而不是仅说“都是高性能CPU”。两颗处理器在实际笔记本中的持续功耗、软件表现可能改变差距。[6]
- **Core Ultra 9 290HX Plus、Ryzen 9 9955HX、Apple M5 Max 18核**在上述多核基准榜单中处于相近的高段位；**不能**据几个百分比的榜单差距断言全部工作负载必然同顺序。[5]
- **Core Ultra X7 358H 与 Core Ultra 7 356H**在榜单上处于相近的中高多核段位；但两者的**集成GPU可能不同**，不能从CPU跑分推出GPU排序。[5]

### CPU 应分开的能力

1. **多核性能**：优先用同口径CPU Mark、多核 Cinebench 或具体编译/渲染测试。
2. **单核性能**：优先用同口径单核成绩；对轻量交互和部分软件响应更相关。
3. **能效与续航**：上述 CPU Mark 分数不能推导，需整机同条件测试。
4. **软硬件兼容性**：尤其跨 Windows x86、Windows on ARM 与 macOS 时，先确认应用支持。

## 5C. GPU 移动端性能梯队：可以粗略区分，但不能只按“核显/独显”排

下面给出**移动GPU的图形性能参考梯队**。它服务于一般3D图形/游戏负载的初步分类；不是渲染器、AI框架、视频编解码和全部游戏的共同排名。例子来自 Notebookcheck 的移动GPU榜单及 Arc B390 专项测试。[7][8]

| 参考定位 | 典型GPU（举例） | 有依据的理解 |
|---|---|---|
| 极高移动图形性能 | RTX 5080 / 5090 Laptop GPU | 在公开综合图形测试中处于移动GPU前列；仍须考虑笔记本功耗和售价 |
| 高移动图形性能 | RTX 5070 Ti Laptop GPU、部分高功耗上一代高端独显 | 通常明显强于主流核显；适合考虑较重图形负载 |
| 中高移动图形性能 | RTX 5060 Laptop GPU、RTX 4060 Laptop GPU | 在相近测试口径中可比较，两者都属于主流独显性能区间 |
| 较强核显 / 与入门独显接近的交叠区 | Intel Arc B390、部分高性能AMD Radeon 8xxS核显、部分低功耗RTX 4050 Laptop GPU | **这个区间存在交叠**，不能认为任何独显一定强于任何核显 |
| 主流/较强核显 | Radeon 890M、780M、Intel Arc 130V/140V等 | 能覆盖普通图形任务与部分游戏，具体性能随内存和整机条件变化 |
| 入门集显或型号不明确 | Radeon 740M/840M、部分通用 Intel Graphics | 适于基础显示/日常任务；遇到只写“Intel Graphics”的记录必须确认具体CPU/平台 |
| 未归类 | Apple各代GPU、尚未核验的GPU、名称含糊的记录 | Apple GPU需用相同应用或跨平台基准另行比较；未知不是“性能差” |

**特别注意：** 上表为**大致定位，不是严格的逐行降序排行**。例如某些旧款高功耗独显可以超越更新但低功耗的产品；Apple GPU和 CUDA GPU 的专业软件支持可能比单纯的跑分更加重要。AMD Radeon 8050S/8060S 等高性能集显也不应被普通“核显”标签压到末尾。

### GPU 有实测支持的比较实例

| 比较对象 | 可核实指标/观察 | 可得出的结论 | 不能推出的结论 |
|---|---|---|---|
| RTX 5070 Ti Laptop vs RTX 5060 Laptop | Notebookcheck 汇总的 3DMark Time Spy Graphics 约 16,874 vs 12,052 | 前者在该综合图形测试中明显领先 | 所有笔记本上的游戏帧率都按同样比例领先 |
| RTX 5060 Laptop vs RTX 4060 Laptop | 同指标约 12,052 vs 10,338 | 前者在这一指标中领先 | 所有游戏、功耗设置均领先 |
| Arc B390 vs Radeon 890M | Notebookcheck 对 B390 的测试，在所测综合图形项目中接近两倍、不同项目有差异 | B390 是相当强的核显，不能仅凭“集显”标签低估 | 所有游戏都恰好两倍性能 |
| Arc B390 vs RTX 4050 Laptop | Notebookcheck 测试中 B390 与低功耗 RTX 4050 部分结果接近；高功耗 RTX 4050 可明显领先 | 核显/独显之间存在交叠，必须看功耗和项目 | B390 恒等于任意功耗 RTX 4050 |
| Radeon 780M vs RTX 5060 Laptop | 公开移动GPU榜单将两者放在差距明显的性能区间 | 面向3D游戏/渲染时，应优先检查 RTX 5060 独显机型 | 没有软件条件时直接承诺具体FPS |

这些数据是**网页当前可查的汇总参考值**，不同型号的有效样本数量不相同，均可能随新的测量改变。查询日期：2026-10-28。[7][8]

### 不同任务下，谁更“好”？

- **网页、Office、网课**：较弱的现代GPU通常也够用；CPU响应、内存、重量、续航和价格更可能决定体验，不能把高GPU跑分直接等价为“更值得买”。
- **大型3D游戏**：优先查看专门游戏实测、GPU类型、GPU功耗、显存和散热。通常高功耗RTX独显更有优势，但较强核显也能胜任部分游戏。
- **Blender等GPU渲染**：必须核对相应渲染后端与显存需求；支持CUDA/OptiX的软件中，NVIDIA GPU可能有生态优势，不能只看通用3DMark分数。
- **剪辑和视频转码**：视频编解码器、硬件编码支持、剪辑软件对GPU的支持可能比综合GPU分数更重要。
- **Apple平台创作**：先确认目标程序对 macOS、Metal、统一内存的支持；不要把Apple GPU核心数换算成CUDA核心数。

### 面向 NotePick 的使用建议（非推荐算法）

- **可明确排序**：完整型号匹配、相同测试项目、结果差距明显且来源可信时，可以得出“在该指标中更强”的结论。
- **只能粗略定位**：存在同一产品系列或明显架构差异，但缺少同口径实测时，使用“主流”“中高”等定位，不输出精确差距。
- **不能判断**：型号缺失、测试条件不合、软件/平台不兼容时，返回未知并解释原因。
- **不能简单使用** `GPU_Type = 独显` 作为高性能保证：Arc B390 等强核显可能接近低功耗独显。

## 6. 面向使用场景的硬件知识（不是固定推荐权重）

| 使用场景 | 应重点关注 | 不宜直接作出的结论 |
|---|---|---|
| 日常学习与办公 | 系统兼容性、内存、CPU响应、续航与便携 | “价格更高办公体验一定更好” |
| 编程开发 | 内存、CPU持续性能、SSD、操作系统和开发环境 | “CPU核心越多越适合所有编程任务” |
| 平面设计 | 软件兼容性、内存、屏幕色准和CPU响应 | “显卡型号更高就能替代屏幕质量判断” |
| 视频剪辑 | CPU/GPU加速、媒体编解码、内存、存储、软件生态 | “有独显就必然导出更快” |
| 3D建模/渲染 | GPU渲染支持、显存、CPU、散热 | “同名移动显卡性能完全一致” |

| 便携移动 | 重量、续航、功耗、接口、性能需求的平衡 | “重量最轻就是最合适” |

## 7. 示例：如何描述具体显卡的差异

- **Intel Graphics**：名称覆盖多种处理器平台；未确认具体GPU实现和整机配置时，不给精确游戏性能等级。
- **Intel Arc B390 与 AMD Radeon 780M**：可以分别记录官方规格、架构与应用支持；若没有同口径游戏/图形测试，不强行判断所有任务下的绝对先后。
- **RTX 5060 Laptop GPU 与 RTX 5070 Ti Laptop GPU**：可根据 NVIDIA 官方定位、显存、核心配置和功耗范围做规格比较；但具体笔记本中的实际差距仍须看功耗设置、散热及同条件测试。[3]
- **Apple M 系列 GPU 与 Windows GPU**：优先按目标软件能否在 macOS 上运行、是否原生加速、统一内存容量及同软件实测比较；不要将 CUDA 核心数和 Apple GPU 核心数当作共同尺度。[4]

# 第三层｜不确定性、适用条件与证据管理

## 8. 为什么相同GPU型号可能表现不同

1. **GPU功耗**：笔记本厂商可在允许范围内配置不同功耗，影响持续性能；例如 NVIDIA 官方给 RTX 5060 Laptop GPU 列出的 GPU Subsystem Power 为 45–100 W，RTX 5070 Ti Laptop GPU 为 60–115 W。[3]
2. **散热设计**：热量无法持续排出时可能降频；短跑分与长时间负载不同。
3. **系统内存与内存带宽**：对共享内存核显尤其重要。
4. **显存容量**：模型、材质和分辨率可能超过可用显存。
5. **驱动、软件版本、渲染后端**：同一硬件在不同程序上的优势可能改变。
6. **供电状态与性能模式**：插电/电池、安静/性能模式可能导致不同表现。
7. **产品实际SKU**：官方系列规格中的可选参数未必同时出现在同一销售版本。

## 9. 对每个结论建议保存的证据字段

| 字段 | 含义 |
|---|---|
| `subject` | 芯片/显卡完整型号或具体整机SKU |
| `claim` | 要表达的事实或比较结论 |
| `evidence_type` | `official_spec` / `benchmark` / `review_test` / `qualitative_inference` |
| `source_title` / `source_url` | 证据标题及原始链接 |
| `published_or_checked_at` | 文献发布时间或最后核查时间 |
| `test_context` | 软件版本、整机、功耗、分辨率等适用条件 |
| `confidence` | `high` / `medium` / `low`，并附判断理由 |
| `limitations` | 不能据此推断什么 |

以上为建议的**证据描述字段**，不是要求改动现有电脑 CSV；可以另存为独立知识表或未来数据库。

## 10. 知识不足时应怎样表达

| 已知情况 | 建议表达 | 禁止的表达 |
|---|---|---|
| 只知道“Intel Graphics” | “属于集成GPU，具体图形性能需结合处理器及整机资料进一步确认” | “GPU性能评分85分” |
| 知道 RTX 5060 Laptop 但不知道功耗 | “具备独立GPU，适合进一步评估图形应用；实际表现受功耗/散热影响” | “该机型一定稳定运行某游戏144FPS” |
| 只有厂商规格、没有跑分 | “可确认规格与功能定位，尚不能给出精确性能差距” | “比某GPU快35%” |
| 跨 Apple / Windows 平台比较 | “请先核对目标软件支持，再找同工作流的对比” | “Apple 10核GPU等于某数量CUDA核心” |
| 本地电脑数据缺失 | “此项数据未核实，暂不参与精确比较” | 用0或虚构数值替代缺失 |

## 11. 知识库扩展流程

1. **识别**：提取新CPU/GPU的完整型号及别名。
2. **核验身份**：从官方规格确认品牌、架构、GPU类型及关键硬件字段。
3. **补充定性定位**：描述适合的工作负载；标识“基于规格的推断”。
4. **寻找实测**：有同口径、可追溯的实测时，加入具体比较证据。
5. **记录限制**：功耗、整机、软件和数据日期。
6. **更新**：发现冲突时保存版本与修订理由，不悄悄覆盖原证据。

## 12. 与 NotePick 的边界

本知识库**可以**帮助未来系统：
- 匹配不同语言及格式的CPU/GPU名称；
- 区分集成与独立GPU；
- 说明硬件的大致定位、用途与局限；
- 支持有证据条件下的跨型号性能比较；
- 生成有根据、附不确定性提示的硬件解释。

本知识库**不负责**：
- 直接决定预算筛选区间；
- 预设办公/游戏等场景的固定分数或权重；
- 强制输出三台电脑或某特定产品；
- 根据硬件型号推算官网价格、国补或跨平台实时报价；
- 自动执行联网操作；
- 替代真实整机评测或商品SKU核验。
